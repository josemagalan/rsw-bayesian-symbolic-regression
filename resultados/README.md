# Results

Each script writes its outputs (tables, JSON files with chains and configurations, figures,
`pip freeze`, seeds) to its own sub-folder here, e.g. `resultados/C-005_analisis_cv/` or
`resultados/2026-10-19_E-021/`. Nothing in this folder is versioned; the result files used for
the paper are archived separately (see the paper's *Data and code availability* statement).
Scripts that are run with `--prueba-sintetica` write to `resultados/_pruebas/`.
